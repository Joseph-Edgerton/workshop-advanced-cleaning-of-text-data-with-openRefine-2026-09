### Origin of data

From the Carpentries Incubator lesson plan for Open Refine for Humanities, there is an external dataset that has been modified from the Early English Books Online (EEBO) database. The EEBO collections database contains 1000's of early English works, along with various metadata.
### Dependencies

For this worskhop you need to download and install OpenRefine.

    OpenRefine is a free, open-source Java application. You can download OpenRefine from http://openrefine.org/download.html for Windows, macOS, and Linux. Please download the latest stable version, choosing the option for your operating system.
    Current versions for Windows (with embedded Java) and Mac include everything you need to run OpenRefine. For Windows you can choose between an installer (.exe) file or a zip-archive. The Linux version requires a “Java Runtime Environment” (JRE) installed on your system.
    Please follow OpenRefine’s manual to run it.

### Project goals and description

By the end of the workshop, you will:

    - understand how functions in OpenRefine can interact with text strings
    - observe various workflows in transforming datasets
    - learn ways to add external data to a given dataset

This workshop will involve loading and cleaning a dataset alongside the instructor. We will start by creating a fresh project file.

If you just want to follow along with a completed project, then open the "completed_code" and in OpenRefine "open" that project which will bring the already completed project into your environment.
